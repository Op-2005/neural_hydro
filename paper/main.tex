\begin{abstract}
River basins form a physical network in which water flows downstream, so a basin's
discharge should depend on its upstream neighbors. Yet strong multi-basin LSTMs treat
every basin independently and match physics-based models, and when the river network is
added as graph structure it typically fails to help. We ask whether the network is
genuinely uninformative or is simply being supplied in the wrong form. To separate these,
we run a controlled ablation on stock NeuralHydrology \texttt{cudalstm}, byte-identical
across conditions, in which the only thing that changes is a single input carrying
network information. This removes the architecture, training, and encoding confounds that
muddied prior attempts. On a 183-basin eastern-US sub-network of CAMELS-US, we find that
the network helps only as a \emph{dynamic} signal: adding a basin's fixed topological
position (graph depth, upstream count, upstream area) yields essentially no change in
skill, whether or not the model also has a basin-identity encoding, whereas feeding the
\emph{dynamic upstream discharge} arriving from upstream neighbors improves median test
NSE by $+0.038$ under an observed-flow oracle ($p=2.6\times10^{-17}$, three seeds). The
same network gives opposite outcomes: the information lives in structure-as-flow, not
structure-as-label, which explains in one stroke why static graph approaches have failed.
The gain is real and deployable. It survives a shuffled-flow null control, holds in
log-NSE, and a two-stage model that \emph{predicts} upstream flow from forcings (no ground
truth at inference) recovers $+0.025$ NSE, about 54--72\% of the oracle ceiling and
positive across all three seeds. It is also mechanistic and specific to the real
network. The gain requires the true upstream connectivity, since a degree-preserving random
rewiring of the graph removes most of it ($+0.034$ NSE for true vs.\ rewired edges,
$p=2\times10^{-14}$, three seeds), and it rises with graph depth while vanishing at
headwaters, the signature of physical routing. The effect persists when the heuristic graph
is pruned to hydrography-realistic connectivity. We conclude that river-network structure
improves streamflow LSTMs when, and only when, it is delivered as a dynamic upstream-flow
signal tied to the real network, rather than as a static topological descriptor.
\end{abstract}

\keywords{streamflow prediction, LSTM, river-network topology, CAMELS}

\section{Introduction}

Deep learning has reshaped streamflow prediction. A single Long Short-Term Memory (LSTM) network
trained across hundreds of river basins predicts daily discharge as well as, or better than,
calibrated process-based models, and it does so while sharing one set of parameters across
hydrologically diverse catchments~\cite{kratzert2018,kratzert2019}. These multi-basin models,
however, treat each basin independently: they map a basin's own meteorological forcings to its own
discharge and never use the fact that basins are physically connected. Water flows downstream, so a
basin's discharge depends on what arrives from upstream, yet the standard model is blind to that
structure.

The obvious way to add the structure is to give the model the river network as a graph and let a
graph neural network (GNN) exploit it. This has not worked. Across adjacency definitions, edge
weightings, and network architectures, GNNs on river topology fail to beat an edge-free baseline;
Kirschstein and Sun~\cite{kirschstein2024} report that ``no adjacency definition produced measurable
improvement'' and that performance shows ``almost no sensitivity to the choice of graph topology.''
The result is an unexplained null: either the river network is genuinely uninformative for this
task, or it is being supplied to the model in a form the model cannot use.

We argue for the second reading, and the distinction is the point of the paper. Network structure
can enter a model in two forms. As a \emph{static descriptor}, a basin's fixed position in the graph
(its depth, its number of upstream neighbours, its contributing area) is a constant attached to the
basin. As a \emph{dynamic signal}, the discharge actually arriving from upstream is a time-varying
quantity that changes every day. A model that already memorises per-basin identity gains nothing
from a further constant, but it can gain from a signal that moves. Our hypothesis is that the network
helps only in the second form: structure-as-flow, not structure-as-label.

We test this with a controlled ablation that isolates the one variable in question. Every condition
is the same stock multi-basin LSTM with a byte-identical training configuration, and the only thing
that changes between conditions is a single input channel carrying network information. This removes
the architecture, training, and encoding differences that confound comparisons between bespoke graph
models, so any change in skill is attributable to that input alone. On a 183-basin sub-network of
CAMELS-US in the eastern United States, three findings follow, each established across three seeds.

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item \textbf{Static topology is inert; dynamic upstream flow helps.} Adding a basin's fixed
topological position changes median test NSE by at most $+0.006$ (not significant), whereas feeding
it the dynamic upstream discharge raises NSE by $+0.038$ under an observed-flow oracle
($p=2.6\times10^{-17}$). The same network produces opposite outcomes depending on its form, which
explains directly why static graph approaches have not helped.
\item \textbf{The gain is specific to the real network.} A degree-preserving random rewiring of the
graph retains only about a quarter of the gain (true-versus-random $+0.034$ NSE,
$p=2.3\times10^{-14}$), and the improvement rises with graph depth and vanishes at headwaters, the
signature of physical routing. A fixed upstream-flow input is sharply sensitive to the topology that
GNNs were insensitive to.
\item \textbf{The gain is deployable.} A two-stage model that \emph{predicts} upstream flow from
forcings, and so needs no observed discharge at inference, recovers $+0.025$ NSE, roughly $54$--$72\%$
of the oracle ceiling, and it does so with a fixed one-hop input rather than any learned graph
operator.
\end{itemize}

The contribution is an explanation, not a leaderboard result. The effect sizes are modest and the
study is regional rather than a national benchmark, so we make no state-of-the-art claim. What the
controlled ablation buys is a clean account of \emph{when} river-network structure helps a streamflow
LSTM and why prior graph methods missed it: the information lives in the structure as dynamic flow,
tied to the real upstream connectivity, and it is recoverable without message passing.

\section{Related Work}

\paragraph{Deep learning for streamflow.} LSTMs trained across many basins set the current standard
for daily rainfall--runoff modelling~\cite{kratzert2018,kratzert2019}. Their strength comes from
sharing parameters across catchments while conditioning on static attributes and a basin-identity
encoding, which together let one model reproduce diverse hydrologic behaviour. Mass-conserving and
other physically-structured LSTMs refine this line~\cite{hoedt2021}. All of these models are
per-basin maps from local forcings to local discharge; none uses inter-basin connectivity. Our
baseline is exactly this standard multi-basin LSTM, and our question is what a single input carrying
network information adds to it.

\paragraph{Graph neural networks on river topology.} The natural way to add connectivity is a GNN
over the river graph. Kirschstein and Sun~\cite{kirschstein2024} test this thoroughly, sweeping
adjacency definitions, learned edge weights, and edge orientations across several GNN architectures,
and find no improvement over an edge-free baseline. Our controls mirror their sweep, but on a fixed
upstream-flow input rather than a learned operator, and reach the opposite conclusion: the real
topology matters sharply. The difference is not the graph but the form in which it enters the model.

\paragraph{Why message passing struggles here.} The GNN null has a mechanistic reading. Standard
message passing acts as a low-pass filter on the graph
signal~\cite{topping2022,rusch2022,bodnar2022}, and on the deep, low-branching trees of river
networks this both over-squashes long upstream-to-outlet paths and blunts the directional asymmetry
that flow requires. Jiang et al.~\cite{jiang2025} address this directly with a physics-guided,
direction-aware operator that restores gains where plain GNNs fail. We reach a related endpoint from
the opposite direction: rather than build a directional operator, we supply the routed flow itself as
a static one-hop input, which sidesteps message passing entirely while remaining sensitive to the
upstream structure.

\section{Methodology}

We ask whether river-network structure improves streamflow prediction, and in what form it must be
supplied. To answer this in isolation, every model we compare is the same trained LSTM, and the only
quantity that varies across conditions is one input channel.

\subsection{Setup and notation}
\label{sec:setup}

Let $V$ be a set of river basins, indexed by $i$ and $j$. For basin $i$ on day $t$ we observe five
daily meteorological forcings $\mathbf{m}_i(t)\in\mathbb{R}^5$ (precipitation, shortwave radiation,
maximum and minimum temperature, and vapour pressure), a fixed vector of five static catchment
attributes $\mathbf{s}_i\in\mathbb{R}^5$ (mean elevation, drainage area, mean slope, mean
precipitation, and mean potential evapotranspiration), and observed discharge $q_i(t)\in\mathbb{R}_{\ge 0}$
in mm\,d$^{-1}$, which is the prediction target. Following the multi-basin convention of
Kratzert et al.~\cite{kratzert2019}, each basin also carries a one-hot identity encoding
$\mathbf{e}_i\in\{0,1\}^{|V|}$ that lets a single model specialise to individual basins.

The task is next-day discharge: predict $q_i(t)$ from a length-$L$ window of inputs ending at $t$,
with $L=30$. Models are trained on 1990--1999, validated on 2000--2004, and evaluated on the
held-out 2005--2008 test period. All reported numbers are on the test period.

The river network is a directed graph $G=(V,E)$ whose edges point from upstream to downstream. We
write $\mathcal{P}(i)=\{\,j : (j\!\to\! i)\in E\,\}$ for the \emph{upstream set} of basin $i$, the
basins the graph places upstream of it, and $A_i$ for its drainage area. Basins with
$\mathcal{P}(i)=\varnothing$ are headwaters. Because every edge decreases elevation
(\S\ref{sec:network}), $G$ is acyclic, so graph depth is well-defined as the longest upstream path,
\begin{equation}
\label{eq:depth}
\mathrm{depth}(i) =
\begin{cases}
0 & \text{if } \mathcal{P}(i)=\varnothing,\\[2pt]
1 + \max_{j\in\mathcal{P}(i)} \mathrm{depth}(j) & \text{otherwise,}
\end{cases}
\end{equation}
so headwaters sit at depth $0$ and depth increases downstream. Depth indexes how much upstream flow
a basin receives, and we use it later to test whether any gain follows the routing structure.

\subsection{Base model}
\label{sec:model}

Every condition uses the same stock \texttt{cudalstm} model from the NeuralHydrology
library~\cite{kratzert2022joss}, the standard multi-basin LSTM for rainfall--runoff
modelling~\cite{kratzert2018,kratzert2019}. At day $t$, basin $i$'s inputs over the window
$t\!-\!L\!+\!1,\dots,t$ are concatenated into per-step vectors $\mathbf{x}_i(\cdot)$
(defined in \S\ref{sec:ablation}), passed through a single-layer LSTM with hidden size $H=64$, and
the final hidden state $\mathbf{h}_i(t)\in\mathbb{R}^{H}$ is mapped to the prediction by a linear head:
\begin{equation}
\label{eq:model}
\mathbf{h}_i(t) = \mathrm{LSTM}\!\big(\mathbf{x}_i(t\!-\!L\!+\!1),\dots,\mathbf{x}_i(t)\big),
\qquad
\hat{q}_i(t) = \mathbf{w}^\top \mathbf{h}_i(t) + b .
\end{equation}
We take the LSTM recurrence as standard~\cite{kratzert2018} and do not restate its gates. What
matters here is the interface: Eq.~\eqref{eq:model} consumes the input vector $\mathbf{x}_i$ that
our ablation modifies. Parameters are trained by minimising the mean squared error between
$\hat{q}_i(t)$ and $q_i(t)$ with Adam (learning rate $10^{-3}$, batch size $256$, $30$ epochs,
gradient-norm clipping at $1$, output dropout $0.4$, initial forget-gate bias $3$). Table~\ref{tab:config}
gives the full configuration, held identical across every condition.

\subsection{Study network and data}
\label{sec:network}

We use the CAMELS US catchment-attributes v2.0 dataset~\cite{addor2017}, which provides static
attributes for 671 contiguous-US catchments, together with the associated daily Maurer-product
forcings and observed streamflow~\cite{newman2015,newman2014data}. Ground-truth river-network
hydrography is not distributed with the attributes, so we infer directed edges from catchment
geometry. A directed edge $(j\!\to\!i)$ is placed when basin $i$ is plausibly downstream of $j$:
\begin{equation}
\label{eq:edge}
(j\!\to\!i)\in E \iff A_i \ge \rho\,A_j \;\wedge\; \mathrm{elev}(i) < \mathrm{elev}(j) \;\wedge\; d(i,j)\le D_{\max},
\end{equation}
with area ratio $\rho=1.5$, decreasing elevation, and a maximum inter-gauge distance
$D_{\max}=150$\,km. Because the geometric rule connects a basin to every qualifying upstream basin
within range, the upstream set of a basin includes indirect ancestors as well as direct neighbours:
about a third of the inferred edges are transitive, and the mean in-degree of $4.2$ exceeds the two
or three tributaries of a typical confluence. These edges are heuristic rather than surveyed
hydrography, and they over-connect. We therefore do not rely on their exact structure. The graph
controls of \S\ref{sec:feature} test whether the signal is specific to the inferred topology at all,
and \S\ref{sec:res-robust} shows the result is unchanged when the graph is pruned to a
hydrography-realistic in-degree. From the national graph we take the largest weakly-connected
component, ``Component~0'', the connected sub-network on which the routing question is well-posed: a
$183$-basin network in the eastern US spanning six HUC regions, with $624$ inferred edges and depth
up to $4$.

\subsection{The controlled ablation}
\label{sec:ablation}

The network enters the model through the per-step input vector. Writing $u_i(t)\in\mathbb{R}$ for a
single scalar that carries structural information (defined in \S\ref{sec:feature}), each condition
uses
\begin{equation}
\label{eq:input}
\mathbf{x}_i(t) = \big[\;\mathbf{m}_i(t)\;\|\;\mathbf{s}_i\;\|\;\mathbf{e}_i\;\|\;u_i(t)\;\big],
\end{equation}
where $\|$ denotes concatenation. The baseline condition $\mathrm{L}$ omits the final coordinate.
Across every other condition the forcings, static attributes, and identity encoding are identical,
and \emph{only the last coordinate $u_i(t)$ changes.} Any difference in test skill between two
conditions is therefore attributable to $u_i(t)$ alone. This design removes the architecture,
training-budget, and encoding confounds that make results from bespoke graph models hard to
interpret: a measured difference reflects the structural signal, not the machinery around it.

\subsection{The structural signal}
\label{sec:feature}

The structural coordinate $u_i(t)$ aggregates the discharge of the basins upstream of $i$. We use the
area-weighted mean of their discharge, lagged by $\tau=1$ day:
\begin{equation}
\label{eq:feature}
u_i(t) =
\begin{cases}
\dfrac{\displaystyle\sum_{j\in\mathcal{P}(i)} A_j\, q_j(t-\tau)}
      {\displaystyle\sum_{j\in\mathcal{P}(i)} A_j}
  & \text{if } \mathcal{P}(i)\neq\varnothing,\\[14pt]
0 & \text{if } \mathcal{P}(i)=\varnothing.
\end{cases}
\end{equation}
Two properties of Eq.~\eqref{eq:feature} matter. First, it carries the units of the target: $A_j q_j$
has units km$^2\cdot$mm\,d$^{-1}$, and dividing by $\sum_j A_j$ returns mm\,d$^{-1}$, so $u_i$ lives
on the same scale as $q_i$. Taking the mean rather than the sum keeps a single large parent from
dominating. Second, and central to our claims, $u_i(t)$ is a \emph{fixed, directed precomputation}: its weights
are drainage areas rather than learned parameters, its lag is fixed, and it is computed once before
training from the graph predecessors of each basin. It is not message passing and performs no learned
aggregation or iteration over the graph. The empirical question is whether this minimal structural
input helps where learned graph operators have not.

Eq.~\eqref{eq:feature} introduces no target leakage. It aggregates the discharge of \emph{upstream}
basins, so basin $i$'s own discharge never enters its input, and it is lagged, so no same-day
information is used.

The conditions of the ablation are instantiations of Eq.~\eqref{eq:feature} that differ only in the
discharge term $q_j$ or the parent set $\mathcal{P}(i)$, summarised in Table~\ref{tab:conditions}.
The \emph{oracle} uses observed upstream discharge and bounds the achievable gain.
The \emph{null} replaces $q_j(t-\tau)$ with the same series permuted in time, holding input scale and
capacity fixed while destroying temporal information. Two graph controls alter $\mathcal{P}(i)$: a
\emph{reversed} variant that draws parents from downstream neighbours (edges reversed), and a
\emph{random} variant that rewires edges while preserving each basin's in-degree. The \emph{realizable}
condition uses predicted rather than observed upstream discharge and is defined next.

\subsection{The deployable two-stage model}
\label{sec:realizable}

The oracle requires observed upstream discharge at inference, which a deployed forecaster does not
have. We therefore define a two-stage realizable model that uses only forcings at inference. In
stage one, the trained baseline $\mathrm{L}$ (Eq.~\eqref{eq:model} with the plain input) predicts
each basin's discharge from its own forcings and attributes over the full record, yielding
$\hat{q}_j(t)$ for all $j,t$. In stage two, we substitute these predictions into
Eq.~\eqref{eq:feature},
\begin{equation}
\label{eq:realizable}
u_i^{\mathrm{real}}(t) =
\frac{\sum_{j\in\mathcal{P}(i)} A_j\, \hat{q}_j(t-\tau)}
     {\sum_{j\in\mathcal{P}(i)} A_j},
\end{equation}
and train a downstream model on inputs carrying $u_i^{\mathrm{real}}$. Because $\hat{q}_j$ depends
only on forcings, this model needs no observed discharge at inference. It recovers a fraction of the
oracle gain that we quantify in \S\ref{sec:results}.

\subsection{Skill metrics}
\label{sec:eval}

We evaluate per basin on the test period with three complementary metrics. The primary metric is the
Nash--Sutcliffe efficiency,
\begin{equation}
\label{eq:nse}
\mathrm{NSE}_i = 1 - \frac{\sum_t \big(q_i(t)-\hat{q}_i(t)\big)^2}{\sum_t \big(q_i(t)-\bar{q}_i\big)^2},
\end{equation}
where $\bar{q}_i$ is the mean observed discharge. NSE takes values in $(-\infty,1]$, with $1$ a
perfect fit and $0$ the skill of predicting the mean. Because NSE is dominated by high flows, we also report a log-space
variant $\mathrm{logNSE}_i$, computed as Eq.~\eqref{eq:nse} on $\log(q+\epsilon)$ with
$\epsilon = 10^{-3}\cdot\max(\bar{q}_i,10^{-6})$ scaled to each basin's mean flow, and the
Kling--Gupta efficiency
\begin{equation}
\label{eq:kge}
\mathrm{KGE}_i = 1 - \sqrt{(r-1)^2 + (\beta-1)^2 + (\gamma-1)^2},
\end{equation}
where $r$ is the correlation between $q_i$ and $\hat{q}_i$, $\beta=\bar{\hat q}_i/\bar q_i$ is the
bias ratio, and $\gamma=(\sigma_{\hat q_i}/\bar{\hat q}_i)/(\sigma_{q_i}/\bar q_i)$ the ratio of
coefficients of variation. KGE separates timing ($r$), bias ($\beta$), and variability ($\gamma$),
which we use to locate where a metric change originates. The comparison protocol built on these
metrics is described in \S\ref{sec:protocol}.

\section{Experimental Protocol}
\label{sec:protocol}

The value of a controlled ablation rests on the control actually holding. This section states the
protocol that makes each measured difference interpretable: an auditable single-variable design, a
pre-registered analysis plan, a paired multi-seed comparison, and a reproducible artifact trail. The
effect sizes we report are modest, so this apparatus is what separates a real signal from an
artifact, and we describe it in the detail a reader would need to reproduce or challenge our claims.

\subsection{A single-variable design, verified}
\label{sec:protocol-design}

Every condition is the model and training of Table~\ref{tab:config}, and the conditions differ only
in the input coordinate $u_i(t)$ of Eq.~\eqref{eq:input} (Table~\ref{tab:conditions}). We do not take
this on trust: the run configurations are stored, and a direct configuration diff confirms that the
four headline conditions ($\mathrm{L}$, oracle, realizable, null) are identical in model, hidden
size, dropout, forget bias, optimiser, learning rate, batch size, epoch count, sequence length,
forcings, static attributes, identity encoding, split, and seed. The only field that differs is the
additional feature file supplying $u_i(t)$. This turns ``the difference-maker is our input'' from an
assertion into a checkable property of the configurations, and it is the specific control that a
bespoke graph model, with its own architecture and training loop, cannot offer.

\subsection{Pre-registration}
\label{sec:protocol-prereg}

Each experiment was pre-registered before its runs were observed. A registration fixes the
hypothesis, the success threshold, and the falsification criterion in advance, so that an outcome
cannot be reinterpreted after the fact. This discipline is load-bearing here, because it commits us
to reporting results that did not go our way. Two examples recur in the results. A null control was
registered to pass only if a time-shuffled upstream input produced negligible gain, which would have
undercut the whole study had it failed. A same-day-lag variant was registered as a stronger form of
the deployable model and then \emph{falsified}: it underperformed the one-day lag, and we report it
as such rather than dropping it. Falsified pre-registrations are reported, not redesigned.

\subsection{Comparison protocol}
\label{sec:protocol-compare}

Our unit of comparison is the paired, per-basin change in skill against the shared baseline. For a
condition $c$,
\begin{equation}
\label{eq:delta}
\Delta_i^{(c)} = \mathrm{NSE}_i(c) - \mathrm{NSE}_i(\mathrm{L}).
\end{equation}
Pairing per basin removes basin-level difficulty and isolates the effect of $u_i(t)$: a basin that is
hard for $\mathrm{L}$ is equally hard for $c$, and only the change matters. We summarise a condition
by the cross-basin median of $\Delta_i^{(c)}$ and test it against zero with a one-sided Wilcoxon
signed-rank test, a paired non-parametric test appropriate for the skewed, non-Gaussian distribution
of per-basin skill. Every condition is trained under three seeds ($11,13,17$). We report the
cross-seed mean and standard deviation of the median and pool basins across seeds for the
significance tests. A structural claim is credited only when it holds across seeds, not in one.

\subsection{Reproducibility and compute}
\label{sec:protocol-repro}

The study runs entirely on a stock model with published configurations, so its artifacts are
complete and its cost is modest: each condition is a single \texttt{cudalstm} trained for $30$
epochs on $183$ basins, and the full study is a few dozen such runs across conditions and seeds. We
retain, for every run, the exact configuration and the per-basin test predictions and metrics, so
that every number in this paper can be recomputed from stored outputs without retraining. The
structural inputs are deterministic functions of the released discharge and the inferred graph, and
the graph follows from Eq.~\eqref{eq:edge}. Both are regenerable from the public dataset. Code and
configurations are released.

\section{Results}
\label{sec:results}

All numbers are cross-seed medians on the held-out test period (2005--2008), with paired per-basin
deltas against the shared baseline $\mathrm{L}$ (Eq.~\eqref{eq:delta}). We report deltas over the
full $183$ basins for the headline conditions, and over the connected basins (those with upstream
parents) for the graph controls, where the manipulation is defined. We state the basin set each time.

\subsection{Static topology is inert, but dynamic upstream flow helps}
\label{sec:res-contrast}

We first ask whether a basin's fixed position in the network improves prediction. Adding the five
static topology features (graph depth, upstream count, upstream area, in-degree, and upstream-area
fraction) leaves skill unchanged: the paired median $\Delta$NSE is $+0.002$ with the basin one-hot
present ($p=0.67$, three seeds) and $+0.006$ without it ($p=0.28$). Both are indistinguishable from
zero. The one-hot itself is worth a real $+0.016$ NSE ($p=3\times10^{-8}$), which explains the null:
a constant per-basin descriptor is redundant with an encoding that already memorises per-basin
identity. Static structure, supplied as a label, carries no usable signal here.

The same network supplied as \emph{flow} behaves in the opposite way. Feeding each basin the
area-weighted discharge of its upstream neighbours raises median test NSE from $0.653$ to $0.691$, a
paired gain of $+0.038$ ($p=3\times10^{-17}$) under the observed-flow oracle
(Table~\ref{tab:main}). The deployable model that predicts upstream flow from forcings recovers
$+0.025$ ($p=6\times10^{-19}$), which is $54$--$72\%$ of the oracle ceiling across seeds. Same network,
opposite outcomes: the information is in the structure as time-varying flow, not as a fixed
descriptor. This contrast is the core result, and it explains directly why methods that inject the
network as a static graph label have not helped.

\subsection{The gain is real, not added capacity}
\label{sec:res-real}

A skeptic could attribute the gain to the extra input rather than its content. The null condition
tests this: replacing upstream discharge with its time-shuffled copy preserves input scale and
distribution but destroys temporal alignment. The realizable model beats this null by a paired
$+0.017$ NSE ($p=2\times10^{-12}$, bootstrap $95\%$ CI $[+0.011,+0.022]$), so the gain is the flow
signal, not capacity. It also survives the choice of metric: the realizable log-NSE gain is $+0.027$
and positive at every seed, so the improvement is not confined to high flows.

The gain is not merely patching a weak baseline. On basins the baseline already predicts well
($\mathrm{NSE}>0.6$), the realizable model still adds $+0.012$, and Figure~\ref{fig:cdf} shows the
improvement as a rightward shift of the entire distribution of per-basin NSE rather than a lift of a
poor tail. Finally, the learned model earns its complexity against a non-learned alternative: a
linear routing predictor fit on upstream flow alone reaches median NSE $0.324$, and one that also
uses the baseline's own prediction reaches $0.664\pm0.008$, both below the realizable LSTM at
$0.683\pm0.008$ (connected basins, three seeds). The LSTM's advantage is that it integrates upstream
flow with local rainfall--runoff, which linear routing cannot.

\subsection{The mechanism is routing on the real network}
\label{sec:res-mechanism}

If the gain reflects physical routing, it should grow with how much upstream flow a basin receives
and vanish where it receives none. It does. The median realizable $\Delta$NSE rises monotonically
with graph depth, from $+0.002$ at headwaters (not significant, $p=0.24$) to $+0.020$, $+0.031$, and
$+0.044$ at depths one through three (each $p<10^{-3}$), and is statistically absent exactly at the
headwaters that have no upstream input (Figure~\ref{fig:depth}). This depth gradient is not a proxy
for basin size or feature magnitude: it survives partial correlation against drainage area and
against the magnitude of the upstream-flow input itself.

The gain is specific to the \emph{real} river network, not to spatial aggregation in general. We
test this by rebuilding the upstream-flow input on altered graphs. Reversing every edge, so a basin
reads its downstream rather than upstream neighbours, weakens the gain from $+0.046$ to $+0.031$
(connected basins). Rewiring the graph at random while preserving each basin's number of parents
weakens it further, to $+0.012$. The true-versus-random gap is $+0.034$ ($p=2\times10^{-14}$, three
seeds): a degree-preserving random graph retains only about a quarter of the gain. The signal lives
in the actual upstream connectivity. This mirrors, in reverse, the finding of
Kirschstein and Sun~\cite{kirschstein2024} that graph neural networks are insensitive to the river
topology, showing ``almost no sensitivity to the choice of graph topology''; a fixed upstream-flow
input is sharply sensitive to it.

The reversal result also bounds how far we push directionality. Downstream flow is correlated with a
basin's own discharge through shared weather and routed water, so reversing edges does not erase the
signal, and the forward-over-reversed advantage is small and inconsistent across seeds. We therefore
report a preference for the physically-correct upstream direction as a mild, aggregate-level effect
rather than a firm claim. The robust and significant statement is topology specificity, not strict
directionality.

\subsection{The result does not depend on the heuristic graph}
\label{sec:res-robust}

Because our edges are inferred and over-connect (\S\ref{sec:network}), we check whether the gain is
an artifact of their density. Pruning the graph to a hydrography-realistic in-degree of at most two,
keeping each basin's nearest upstream neighbours, removes more than half the edges. The realizable
gain is unchanged: $+0.025$ on the pruned graph versus $+0.026$ on the full graph, positive at all
three seeds ($p=1\times10^{-14}$). The routing benefit rests on the physically meaningful
nearest-upstream structure, not on the excess edges the heuristic adds.

\section{Discussion}

Our results give the unexplained GNN null a concrete cause. River-network structure is not
uninformative for streamflow; it was being supplied in the wrong form. Encoded as a static
descriptor, network position is redundant with the basin-identity encoding a multi-basin LSTM
already carries, and it adds nothing. Encoded as the dynamic flow arriving from upstream, the same
structure carries real, time-varying information and improves prediction. This resolves the tension
between the network's evident physical relevance and its apparent uselessness in prior graph models:
the models were reading structure-as-label, and the signal is in structure-as-flow.

The finding connects the two prior results it sits between. It explains Kirschstein and Sun's
null~\cite{kirschstein2024} by locating the missing signal in a channel their adjacency-based GNNs
did not use, and it realises the direction Jiang et al.~\cite{jiang2025} pointed to, that flow
dynamics demand a topology-aware and direction-sensitive treatment, using a fixed one-hop input
rather than a learned operator. That a non-learned feature recovers the benefit is itself
informative: for this task, the value of the network is in the routed flow it summarises, not in any
capacity to learn how to combine neighbours.

We state the broader reading as a hypothesis this study instantiates rather than establishes. When a
sequence model already conditions on node identity, spatial graph structure may help it only as
time-varying state, not as a fixed descriptor. Whether this holds beyond streamflow, in other
physical networks where an identity-aware predictor meets a routing process, is an open question our
single domain cannot answer.

\section{Limitations}

The study is regional. It covers 183 basins in the eastern United States, which is adequate for a
controlled study but is not a national benchmark, and our baseline is a stock \texttt{cudalstm}
rather than a tuned state-of-the-art model. We therefore make no claim about absolute
state-of-the-art skill, only about the paired effect of the structural input. Whether the effect
holds at national scale is untested.

The edges are inferred from catchment geometry, not surveyed hydrography. We show the result is
robust to their density by pruning to a hydrography-realistic graph, but a validation against
ground-truth flowlines remains future work. The effect sizes are modest in absolute NSE, which we
report plainly; the contribution is the explanation of when structure helps, not a large performance
gain. The directional component of the mechanism is weak: reversing edges does not erase the signal,
so we report a preference for the upstream direction as a mild aggregate effect rather than a firm
claim, and rest the mechanistic argument on topology specificity, which is strong and significant.
Finally, each condition is trained under three seeds with a single run per seed, sufficient for the
paired medians and cross-seed agreement we report but not a large-sample sweep.

\section{Conclusion}

River-network structure improves streamflow LSTMs when, and only when, it is supplied as a dynamic
upstream-flow signal tied to the real network, rather than as a static topological descriptor. A
controlled ablation on a stock multi-basin LSTM shows static topology to be inert while dynamic
upstream flow gives a real, deployable, and routing-specific gain, which explains why static graph
approaches have not helped and does so without any message-passing machinery. The natural next steps
are a national-scale test and a validation against ground-truth hydrography, both of which the
released code and configurations are set up to support.
