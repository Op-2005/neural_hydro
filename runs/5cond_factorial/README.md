# 5-Condition Factorial — Run Outputs

Output folder for the 5-condition × 3-seed factorial ablation on Component 0
(183 basins). Generated by the Colab notebook in
`../../experiments/5cond_factorial/notebooks/colab_5cond_run.ipynb`.

For the protocol see `../../idea1.md` §"Revised Framework — 5-Condition Factorial Ablation"
and `../../experiments/5cond_factorial/README.md`.

## Expected runs (15 total)

Naming convention: `<condition>_seed<N>/` with N ∈ {11, 13, 17}.

| Condition | Run folders |
|---|---|
| L (NH cudalstm baseline) | `L_seed11/`, `L_seed13/`, `L_seed17/` |
| G (DirectedGraphLSTM, empty edges) | `G_seed11/`, `G_seed13/`, `G_seed17/` |
| G+T (DirectedGraphLSTM, +topology features) | `G_T_seed11/`, `G_T_seed13/`, `G_T_seed17/` |
| G+M (DirectedGraphLSTM, full graph + messages) | `G_M_seed11/`, `G_M_seed13/`, `G_M_seed17/` |
| G+T+M (DirectedGraphLSTM, both) | `G_T_M_seed11/`, `G_T_M_seed13/`, `G_T_M_seed17/` |

## Per-run contents

For NH cudalstm runs (Condition L):
```
L_seed{N}/
├── config.yml
├── model_epoch001.pt ... model_epoch030.pt
├── output.log
├── train_data/
└── test/model_epoch030/test_metrics.csv
```

For DirectedGraphLSTM runs (Conditions G, G+T, G+M, G+T+M):
```
<cond>_seed{N}/
├── run_config.json
├── model_epoch001.pt ... model_epoch030.pt
└── test_metrics.csv
```
