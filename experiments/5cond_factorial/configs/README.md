# 5cond_factorial configs

Per-seed YAML configs for the **Condition L** runs in the 5-condition factorial. Auto-generated by the Colab notebook (`../notebooks/colab_5cond_run.ipynb`, Cell 7) from `../../configs/lstm_component0_baseline.yaml`, but also checked in here as standalone reviewable templates.

| File | Used by | Purpose |
|---|---|---|
| `L_seed{11,13,17}.yaml` | `neuralhydrology/nh_run.py train` | Condition L (cudalstm baseline) at full 30-epoch training. Output → `runs/5cond_factorial/L_seed{N}/`. |
| `L420_seed{11,13,17}.yaml` | `experiments/training/train_matched_budget_lstm.py` | Matched-budget control (Step 1 of testing framework). 1 epoch, max_updates_per_epoch=420. Output → `runs/5cond_factorial/L420_seed{N}/`. |

Each config differs from the next only by `experiment_name`, `seed`, and (for L420) the `epochs`/`max_updates_per_epoch` pair. All other hyperparameters are identical and locked to the 5cond protocol.

Graph variants (G, G+T, G+M, G+T+M) do not use YAML configs — they're driven entirely by CLI flags to `experiments/training/train_graph_component0.py`. See `../README.md` for the variant flag table.
