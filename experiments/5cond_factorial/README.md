# 5-Condition Factorial Ablation — Experiment Master Folder

Self-contained workspace for the **5-condition × 3-seed factorial ablation**
on Component 0 (183 basins). This is the methodologically rigorous successor
to the single-seed A/B/C run from May 2026 (`runs/14_*`, `15_*`, `16_*`),
designed to eliminate the architecture confound and the missing-combination-
cell limitations of that earlier run.

For the research direction and full protocol see `../../idea1.md`
§"Revised Framework — 5-Condition Factorial Ablation (2026-05-06)".

## Reporting

Three metrics computed for every condition: **NSE**, **KGE**, **log-NSE**.
Six clean pairwise contrasts plus an interaction term. Per-basin
distributions, depth-stratified medians, area-stratified medians,
outlier-trimmed means.

Output of the analysis script (`../analysis/compare_5conditions.py`) lands at
`../analysis_outputs/5cond_component0/` and includes a slideshow-ready
`RESULTS.md`.
