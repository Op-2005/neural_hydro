# analysis/ — re-analysis of stored runs (zero training)

Each file is a Markdown result produced by an `analyze_*.py` / `build_*.py` script in the parent
directory, consuming the `test_metrics.csv` / `test_results.p` under
`runs/topology_ablation/component0/`. `PAPER_TABLE.md` is the consolidated table the paper draws from.

| File | What it establishes |
|---|---|
| `RESULTS.md` | Static-topology 2×2 (single-seed) — does network position help, and when |
| `RESULTS_2X2_MULTISEED.md` | Static-topology 2×2, 3-seed — static features are inert (the paper's static null) |
| `MULTISEED.md` | 3-seed confirmation of the upstream-signal headline |
| `SIGNIFICANCE.md` | Deployable (realizable) gain: paired Wilcoxon vs L and vs the null |
| `COMPLIANCE.md` | Gain persists on already-well-predicted basins (not baseline-rescue) |
| `DEPTH_SIGNIFICANCE.md` | Per-depth Wilcoxon: gain present at depth≥1, absent at headwaters |
| `CONFOUND.md` | Depth gradient vs basin size (n_upstream vs area) |
| `FEATURE_MAGNITUDE_CONFOUND.md` | Partial Spearman: depth survives area + feature magnitude |
| `METRIC_HONESTY.md` | log-NSE eps-sensitivity + KGE decomposition |
| `ROUTING_BASELINE.md` / `ROUTING_BASELINE_3SEED.md` | No-ML routing baselines (R1/R2) vs the LSTM |
| `GRAPH_ROBUSTNESS.md` | R1-proxy: gain lives in nearest-parent structure, not excess edges |
| `K2_GRAPH_CHECK.md` | k=2 pruned-graph model check, 3-seed — not a heuristic-density artifact |
| `DIRECTIONALITY.md` | Single-seed directionality controls (superseded by MECHANISM_MULTISEED) |
| `MECHANISM_MULTISEED.md` | **forward / reversed / random / distance-control, 3-seed.** Holds the 2026-08-10 distance-control result that FALSIFIES topology-specificity (the gain is proximity, not the true topology). |
| `STAGE1_GAP.md` | Stage-1 (predicted-upstream) train vs test degradation for the realizable model |
| `PAPER_TABLE.md` | **Consolidated publication table** — generated by `../build_paper_table.py` (ΔNSE = paired per-basin median, matches the paper) |
| `contrasts.csv`, `table.csv` | tabular dumps used by the above |

Regenerate any file by running its script from the repo root, e.g.
`python experiments/topology_ablation/build_paper_table.py`.
