# basin_lists — gauge lists for the early baselines

USGS gauge IDs, one 8-character ID per line, referenced by the configs in `../configs/` and the
trainers in `../training/`. Covers the 23-basin Texas pilot and its held-out-basin (PUB) split,
where a few basins are excluded from training so the model must predict them without ever having
seen their discharge.

The **183-basin study network** used by the paper is not here: it is generated by the network
construction in `topology_analysis/`, so that the basin set and the edge lists cannot drift apart.
The regional subgraph lists live with the experiment that built them, in
`../local_subgraphs/basin_lists/`.
